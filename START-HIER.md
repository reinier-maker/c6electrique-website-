# Start hier

Dit is je website. Je hoeft er zelf niets van te begrijpen: Claude leest de instructies die in
deze map staan en praat je er stap voor stap doorheen.

## Wat je doet

1. Pak deze map uit op je computer.
2. Open Claude Code in deze map. Nog niet geïnstalleerd? Ga naar https://claude.com/code en volg
   de installatie. Daarna: open de Terminal, typ `cd ` met een spatie, sleep deze map het venster
   in, druk op Enter, en typ `claude`.
3. Typ `hoi` en druk op Enter.

Dat is alles. Claude weet vanaf daar wat er moet gebeuren, legt uit wat hij doet en vraagt om wat
hij nodig heeft.

## Werk je liever in Claude in de browser of de app?

Open een nieuw gesprek, sleep de bestanden `CLAUDE.md` en `cms-herstel.sql` erin en typ:
`lees CLAUDE.md en begeleid me`. Claude kan dan niet zelf op je computer werken, maar loodst je er
wel doorheen.

## Wat je onderweg zelf aanmaakt

Alle drie gratis, en de eerste twee heb je echt nodig:

- github.com, hier komt de code van je site te staan
- vercel.com, hier komt de site op internet
- supabase.com, alleen als je teksten wilt kunnen wijzigen via het beheerscherm op `/admin`

Claude vraagt er op het juiste moment naar. Je wachtwoorden houd je voor jezelf, die vult Claude
nooit in.
